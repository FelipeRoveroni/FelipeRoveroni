**Desenvolvedor de automações e integrações | Python • APIs • Oracle**

Trabalho na construção de soluções que automatizam processos e conectam sistemas, com foco em integrações fiscais e desenvolvimento back-end.

### Sobre mim

- 🧾 Atuo com emissão, consulta e captura de documentos fiscais, como NFS-e, NF-e e CT-e.
- 🔗 Desenvolvo APIs e integrações em Python, incluindo comunicação com serviços da SEFAZ, ADN e SERPRO Integra Contador.
- 🗄️ Trabalho com Oracle SQL, PL/SQL e APEX para tratar dados, criar rotinas e apoiar processos de integração.
- 🧪 Tenho interesse em arquitetura de APIs, versionamento, testes automatizados e execução de aplicações com Docker.

### Formação

- 🎓 Cursando **Análise e Desenvolvimento de Sistemas** na **FIAP**.
- 📚 Cursando **MBA em Engenharia de Software** na **USP/Esalq**. Meu TCC investiga versionamento de APIs REST e compatibilidade entre clientes e serviços.

### Projetos em destaque

- **[Experimento de versionamento de APIs REST](https://github.com/FelipeRoveroni/tcc-api-versioning-experiment)** — API em FastAPI que compara estratégias de versionamento com testes automatizados.
- **[MoneyTrack](https://github.com/FelipeRoveroni/moneytrack)** — projeto de API para controle financeiro, com persistência de dados, migrações e testes.
